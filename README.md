# emerald-portfolio

Kişisel portföy ve teknik içerik web sitesi için başlangıç projesi.

## Başlatma

1. Yerel bilgisayarda klasörü açın.
2. Terminalde aşağıdaki komutları çalıştırın:

```bash
python3 -m http.server 8000
```

3. Tarayıcıda şu adresi açın:

```text
http://localhost:8000
```

## GitHub Pages için yayınlama

Bu repo `EmeraldZehra/emerald-portfolio` olarak oluşturuldu. GitHub Pages kullanmak için aşağıdaki seçeneklerden birini seçebilirsiniz:

### Seçenek 1: Repo adını `EmeraldZehra.github.io` yapma
Eğer doğrudan `https://EmeraldZehra.github.io` adresini istiyorsanız, işte o zaman repo adını şu şekilde oluşturmanız gerekir:

```text
EmeraldZehra.github.io
```

Böylece GitHub Pages otomatik olarak ana sayfayı yayınlar.

### Seçenek 2: Mevcut repo ile yayınlama
Bu repo için GitHub Pages üzerinden şu URL oluşur:

```text
https://EmeraldZehra.github.io/emerald-portfolio/
```

Bu nedenle GitHub Settings > Pages menüsünden public branch olarak `main` seçilebilir.

## İçerik düzenleme

- `index.html` sayfa yapısını içerir.
- `styles.css` stil düzenini tanımlar.
- `script.js` küçük etkileşim ve dinamik içerik ekler.

İsterseniz bir sonraki adımda bu sayfayı sizin gerçek bilgilerinizle özelleştirebiliriz.
